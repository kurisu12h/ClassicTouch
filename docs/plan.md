## Known facts and things to verify

- The StikDebug on the phone is our own build (`org.classictouch.dev.stikdebug`, source in `work/ios/stikdebug/`, 3.2.0). So that tests need no taps, M1 turned off its "ask for confirmation when an external request enables JIT" prompt (`confirmExternalJITRequests = false`); the pairing file is in `work/ios/secrets/` (mode 600); it amounts to an access credential for the phone and never goes into the repository.
- Development signing: Xcode already has the paid personal team; M1 installed with its existing wildcard provisioning profile, without creating a new App ID. The team ID stays out of the repository. After release, users each sign with their own Apple ID through AltStore/SideStore, which does not involve our account.
- The iPod touch 2nd gen needs Apple's SecureROM (`bootrom_240_4`), which by the rules cannot go into the app. A 4-byte placeholder file is used now, and cold boot works. On 2026-11-01 the user decided not to do long standby tests for now; before seeing that decision, M0 had already done one two-minute sleep test on the side: about 30 seconds after the lock screen it entered deep sleep, and after pressing Home the CPU reset to address 0 and hung. The fix is clear: following the 3GS machine's `s5l8920_resume`, add a high-level emulation of wake-up for the iPod 2nd gen as a patch, after which Apple's SecureROM is not needed at all. This will be done when the iPod touch 2nd gen gets official support; until then, avoid letting it enter deep sleep (set Auto-Lock to Never).
