# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be kind, respect different experience and points of view, and discuss the work rather than the person.
- No harassment, personal attacks, discriminatory or sexual content, and no publishing other people's private data (including the UDIDs, serial numbers or accounts of other people's devices).
- Maintainers may remove, edit or reject comments, commits, issues and pull requests that break this code, and may ban someone temporarily or permanently when needed.

## Reporting

To report behavior that breaks this code, contact the repository owner (GitHub user kurisu12h) privately. If you cannot, open an issue that only says "requesting private contact", without details. Maintainers will reply as soon as they can and keep the reporter's identity confidential.

This code applies in all project spaces (issues, pull requests, discussions) and in public spaces when someone represents the project.
